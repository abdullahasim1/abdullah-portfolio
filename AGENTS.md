# Project Notes

## Git Workflow (user preference)
Har change ke liye yehi flow follow karein:
1. New branch banao (`git checkout -b <branch-name>`)
2. Commit karo (concise message)
3. Push karo (`git push -u origin <branch-name>`)
4. Main mein merge karo (`git checkout main && git merge <branch-name> && git push origin main`)
